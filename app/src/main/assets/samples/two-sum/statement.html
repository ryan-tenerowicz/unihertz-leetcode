1. Two Sum Easy

You get an array of integers nums and an integer target. Return the indices of the two numbers that add up to target.

Exactly one pair adds up to the target, and you can't use the same element twice. The two indices can be returned in any order.

Example 1

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Why: nums[0] + nums[1] == 9

Example 2

Input: nums = [3,2,4], target = 6
Output: [1,2]

Example 3

Input: nums = [3,3], target = 6
Output: [0,1]

Constraints

  • 2 <= nums.length <= 104
  • -109 <= nums[i] <= 109
  • -109 <= target <= 109
  • There is exactly one answer.

Follow-up: can you do better than O(n2) time?
