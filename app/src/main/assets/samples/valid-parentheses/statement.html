20. Valid Parentheses Easy

The string s contains only the characters '(', ')', '{', '}', '[' and ']'. Return whether it is valid.

A string is valid when:

  1. every opening bracket is closed by a bracket of the same type,
  2. brackets are closed in the right order, and
  3. every closing bracket has a matching opening bracket.

Example 1

Input: s = "()"
Output: true

Example 2

Input: s = "()[]{}"
Output: true

Example 3

Input: s = "(]"
Output: false

Example 4

Input: s = "([])"
Output: true

Constraints

  • 1 <= s.length <= 104
  • s contains only ()[]{}.
