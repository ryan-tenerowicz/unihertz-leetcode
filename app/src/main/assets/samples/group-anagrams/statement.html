49. Group Anagrams Medium

Given a list of strings strs, put the strings that are anagrams of each other in the same group, and return the groups. Groups and the strings inside them can be in any order.

Two strings are anagrams if one is a rearrangement of the other's letters, using every letter exactly once.

Example 1

Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]

Example 2

Input: strs = [""]
Output: [[""]]

Example 3

Input: strs = ["a"]
Output: [["a"]]

Constraints

  • 1 <= strs.length <= 104
  • 0 <= strs[i].length <= 100
  • strs[i] contains only lowercase English letters.
